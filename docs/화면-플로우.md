# 화면 플로우

기준: API-명세서.md (2026-11-25). 디자인은 정하지 않고, 화면 이동과 각 화면에 들어가는 정보만 적었습니다.

## 1. 전체 이동

```mermaid
flowchart TD
    L[로그인<br/>학번·교번·직번, 비밀번호] -->|STUDENT 학부생| S1
    L -->|STUDENT 대학원생 10자리<br/>ta=true| T1
    L -->|PROFESSOR| T1
    L -->|ADMIN| A0
    L -.->|공통 메뉴| PW[비밀번호 변경]

    subgraph 학생
        S1[수강신청<br/>강의 검색 · 장바구니 · 신청 목록] --> S2[내 시간표]
        S1 --> S3[내 성적]
        S1 -.->|planFile 있음| PDF[강의계획서 PDF 보기]
        S1 -.->|학부생인데 ta=true| T1
    end

    subgraph 교수·조교
        T1[담당 강의 목록<br/>학기 선택] --> TD[강의 상세]
        TD --> T2[수강생 명단 탭]
        TD --> T3[강의계획서 탭]
        TD --> T4[조교 탭<br/>담당 교수만]
        TD --> T5[성적 입력 탭]
        T1 -.->|교수| TS[강의 검색]
    end

    subgraph 관리자
        A0[대시보드] --> A1[사용자 관리]
        A0 --> A2[학기·학사일정<br/>최대학점 산정]
        A0 --> A3[과목 관리]
        A0 --> A4[강의 개설 관리]
        A0 --> A5[수강신청 현황]
        A0 --> A6[성적 확정]
        A0 -.->|계획서 미제출 강의| A4
        A0 -.->|정원 마감 강의| A5
        A4 -.->|강의 선택| A5
    end
```

- 대학원생(10자리)은 장바구니·신청·최대학점 대상이 아니므로 학생 수강신청 메뉴를 보여 주지 않습니다. 조교로 배정돼 있으면(`ta`) 강의 운영 메뉴로 갑니다.
- 401이 오면 토큰을 지우고 로그인으로 돌아갑니다.

## 2. 화면별 정보

### 공통

| 화면 | 보여 줄 정보 | 입력·동작 | API |
| --- | --- | --- | --- |
| 로그인 | | 로그인ID, 비밀번호 | `POST /api/auth/login` |
| 상단 바 | 이름, 역할, 조교 여부 | 로그아웃(토큰 삭제), 비밀번호 변경 | `GET /api/auth/me`, `PATCH /api/auth/password` |

### 학생 (학부생)

| 화면 | 보여 줄 정보 | 입력·동작 | API |
| --- | --- | --- | --- |
| 수강신청 | 지금 기간(장바구니·신청·정정, 끝 시각), 신청 대상 학기 | | `GET /api/semesters`, `GET /api/semesters/{semNo}/schedules`, `GET /api/health`(서버 시각) |
| └ 강의 검색 | 과목코드·과목명·분반, 학점, 이수구분, 평가방식, 권장학년, 교수, 영어강의, 정원·신청인원·잔여, 마감 여부, 강의시간·장소, 계획서 유무 | 학과·학년·이수구분·과목명·교수명 검색, 페이지, 담기, 신청, 계획서 보기 | `GET /api/lectures`, `GET /api/lectures/{lecNo}/plan` |
| └ 장바구니 | 담은 강의(과목·분반·학점·교수·정원·신청인원·담은 학생 수·시간), 담은 학점 / 최대학점 | 빼기, 신청 | `GET·POST /api/cart`, `DELETE /api/cart/{lecNo}` |
| └ 신청 목록 | 신청한 강의(과목·분반·학점·교수·재수강·신청일시·시간) | 취소 | `GET·POST /api/enrollments`, `DELETE /api/enrollments/{lecNo}` |
| 내 시간표 | 학기 선택, 요일×시간 칸(과목·장소), 온라인 강의 따로 표시, 총 학점(채플 포함) | 학기 바꾸기 | `GET /api/me/timetable?semNo=` |
| 내 성적 | 학기별 과목(과목코드·과목명·학점·이수구분·등급·평점·재수강·누적 반영 여부), 학기 평점, 누적 평점, 이수 학점 | 학기 선택 | `GET /api/me/grades` |

### 교수·조교

| 화면 | 보여 줄 정보 | 입력·동작 | API |
| --- | --- | --- | --- |
| 담당 강의 목록 | 학기(연도·학기구분), 강의(과목코드·과목명·분반·정원·신청인원·상태·시간) | 학기 선택, 강의 선택 | `GET /api/teaching/lectures?semNo=` |
| 수강생 명단 | 학번, 이름, 학과, 학년, 이메일. 신청 종료 전이면 "아직 볼 수 없음"(`ROSTER_NOT_OPEN`) | | `GET .../{lecNo}/students` |
| 강의계획서 | 계획서 등록 여부, 반영비율(중간·기말·과제·출석), 평가방식, 마감 일시, 수정 가능 여부 | PDF 올리기(10MB), 비율 저장(합 100, P/F는 없음), PDF 보기 | `GET .../{lecNo}/plan`, `PUT .../plan/file`, `PUT .../plan/weights`, `GET /api/lectures/{lecNo}/plan` |
| 조교 (교수만) | 조교 학번·이름·학과·학년·이메일 | 대학원생 학번으로 추가, 삭제 | `GET·POST .../{lecNo}/assistants`, `DELETE .../assistants/{stdNo}` |
| 성적 입력 | 성적상태, 평가방식(상대·절대·P/F), 반영비율, 상대평가 구역(수강인원·A 상한·A+B 상한), 학생별(학번·이름·재수강·네 항목 원점수·원점수 총점·최종점수·등급·평점·입력 여부), 저장·제출 가능 여부 | 원점수 입력(P/F는 P·F 선택), 저장, 제출 | `GET·PUT .../{lecNo}/grades`, `POST .../grades/submit` |
| 강의 검색 (교수) | 학생 강의 검색과 같음 | 검색, 계획서 보기 | `GET /api/lectures` |

### 관리자

| 화면 | 보여 줄 정보 | 입력·동작 | API |
| --- | --- | --- | --- |
| 대시보드 | 학기, 개설 강의 수, 정원 마감 강의, 강의실 미배정 수, 계획서 미제출 강의(파일·비율 없음, 교수 연락처) | 학기 선택 | `GET /api/admin/dashboard?semNo=` |
| 사용자 관리 | 번호, 이름, 이메일, 역할, 계정상태, 학과, 학년·학적(학생), 연구실(교수) | 역할·키워드 검색, 등록, 수정(학적 변경 포함), 비밀번호 초기화, 비활성화 | `/api/admin/users` 계열 |
| 학기·학사일정 | 학기 목록(연도·구분·정규·현재), 학기별 일정(유형·대상학년·기간), 최대학점 산정 결과(학번·이름·학년·학적·최대학점) | 학기 등록·수정, 현재 학기 지정, 일정 등록·삭제, 최대학점 산정 실행(졸업 처리 수·학점별 인원) | `/api/admin/semesters` 계열, `/api/admin/schedules/{schdNo}` |
| 과목 관리 | 과목코드, 과목명, 학과, 학점, 이수구분, 평가방식, 권장학년, 선수과목(최소 등급) | 학과·이수구분·키워드 검색, 등록, 수정, 선수과목 지정 | `/api/admin/courses` 계열 |
| 강의 개설 관리 | 학기별 강의(과목·분반·교수·정원·신청인원·상태·영어강의·상대평가 제외·시간·강의실) | 개설, 수정(기간별 제한), 폐강 | `/api/admin/lectures` 계열 |
| 수강신청 현황 | 강의 정원·신청인원·잔여, 신청 학생(학번·이름·학년·재수강·처리구분·신청일시) | 학생 수동 추가, 관리자 취소 | `/api/admin/lectures/{lecNo}/enrollments` 계열 |
| 성적 확정 | 학기, 성적 입력 마감, 확정 가능 여부, 상태별 강의 수, 강의(과목·분반·교수·연락처·수강인원·성적상태·확정일시) | 상태로 거르기, 선택 강의 확정 | `GET /api/admin/grades`, `POST /api/admin/grades/confirm` |
